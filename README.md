# シラバス解析・比較アプリ

## 概要
履修登録時に複数のシラバスを比較する負担を減らすために
制作したWebアプリです。

## 主な機能
・シラバスの解析
・解析結果の項目別表示
・複数授業の比較

## 使用技術
HTML / CSS / JavaScript / Gemini API
